# 🎮 تطبيق المسابقات الحية - Real-time Quiz App

تطبيق مسابقات حية متقدم يعمل في الوقت الفعلي مع نظام تنافسي مباشر بين المشاركين، مصمم خصيصاً للهواتف الذكية.

## ✨ المميزات الرئيسية

✅ **مسابقات حية في الوقت الفعلي** - تنافس مباشر مع عدة مشاركين  
✅ **نظام نقاط ذكي** - يعتمد على السرعة والدقة معاً  
✅ **واجهة جميلة ومحسّنة للهواتف** - تصميم عصري مع دعم كامل للعربية  
✅ **اتصال فوري عبر WebSocket** - استخدام Socket.io للتزامن الفوري  
✅ **ترتيب حي ولوحة نتائج** - تحديث فوري للنتائج والترتيب  
✅ **Dark Mode جميل** - تجربة بصرية مريحة للعينين  
✅ **صوتيات تفاعلية** - تأثيرات صوتية عند الإجابة  

---

## 🏆 نظام النقاط

| المركز | النقاط |
|--------|--------|
| 🥇 المركز الأول | 100 نقطة |
| 🥈 المركز الثاني | 80 نقطة |
| 🥉 المركز الثالث | 60 نقطة |
| ✅ إجابة صحيحة (4+) | 20 نقطة |
| ❌ إجابة خاطئة | 0 نقطة |

## 📦 التثبيت والتشغيل

### 1️⃣ استنساخ المستودع
```bash
git clone https://github.com/turkik69/realtime-quiz-app.git
cd realtime-quiz-app
```

### 2️⃣ تثبيت المكتبات المطلوبة
```bash
npm install
```

### 3️⃣ بدء الخادم
```bash
npm start
```

أو للتطوير مع إعادة تحميل تلقائية:
```bash
npm run dev
```

### 4️⃣ فتح التطبيق
افتح متصفحك وانتقل إلى:
```
http://localhost:3000
```

## 📱 خطوات اللعب

### 1. شاشة الدخول
- أدخل اسمك
- اختر صورتك الشخصية (Avatar)
- اضغط "دخول المسابقة"

### 2. شاشة الانتظار (اللوبي)
- شاهد عدد اللاعبين المتصلين
- انتظر بدء المسابقة (تبدأ تلقائياً عند وصول 2 لاعب)

### 3. شاشة السؤال
- اقرأ السؤال بعناية
- اختر الإجابة الصحيحة من بين 4 خيارات
- اضغط قبل انتهاء المؤقت (15 ثانية)
- كلما أجبت أسرع = نقاط أكثر

### 4. شاشة النتائج
- شاهد الإجابة الصحيحة
- اطّلع على ترتيب أسرع المجيبين
- شاهد ترتيبك الحالي
- انتظر السؤال التالي

### 5. النتيجة النهائية
- شاهد الترتيب النهائي
- اطّلع على إحصائياتك الكاملة
- اضغط "العب مرة أخرى" للمزيد

## 🏗️ البنية التقنية

### Backend (Server.js)
```
Node.js + Express + Socket.io
├── إدارة الاتصالات الفعلية
├── توزيع الأسئلة
├── حساب النقاط بالملي ثانية
├── إدارة لوحة النتائج
└── معالجة قطع الاتصالات
```

### Frontend (Public folder)
```
HTML5 + CSS3 + JavaScript
├── index.html - البنية الأساسية
├── styles.css - التصميم الحديث (RTL)
└── app.js - منطق التطبيق
```

### المكتبات المستخدمة
- **express** - خادم الويب
- **socket.io** - الاتصال الفوري (WebSockets)
- **cors** - معالجة طلبات عابرة للنطاقات
- **uuid** - توليد معرّفات فريدة

- 📚 التاريخ (2 سؤال)
- 🎓 الثقافة العامة
- 🔬 العلوم
- 🐾 الحيوانات
- 📖 الأدب

## 🔧 إضافة أسئلة جديدة

عدّل ملف `server.js` وابحث عن `QUIZ_DATA`:

```javascript
{
    id: 11,
    question: "سؤالك هنا؟",
    options: ["خيار 1", "خيار 2", "خيار 3", "خيار 4"],
    correct: 0,  // رقم الخيار الصحيح (0-3)
    category: "اسم الفئة"
}
```

## 🎨 التخصيص

### تغيير الألوان
عدّل متغيرات CSS في `public/styles.css`:
```css
:root {
    --primary: #6366f1;      /* اللون الأساسي */
    --secondary: #ec4899;    /* اللون الثانوي */
    --success: #10b981;      /* لون النجاح */
    --danger: #ef4444;       /* لون الخطأ */
}
```

### تغيير مدة السؤال
عدّل في `server.js`:
```javascript
questionTime: 15000, // 15 ثانية (غيّر هنا)
```
